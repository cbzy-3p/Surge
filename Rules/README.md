# NAME: Multi-source Surge Rules

These files are generated by `.github/scripts/update_bm7_rules.py` and synchronized daily by GitHub Actions.

## Source policy

- BM7 `blackmatrix7/ios_rule_script` is the baseline for the requested categories.
- Rabbit-Spec supplements Google, Facebook, Instagram, and TikTok.
- Loyalsoldier supplements Google.
- MetaCubeX contributes only directly corresponding `apple-music`, `apple-tvplus`, `binance`, and `category-cryptocurrency` data.
- v2fly contributes only directly corresponding domain categories.

Supplement sources are converted to `DOMAIN-SUFFIX` only. Their IP, ASN, keyword, and regex rules are not imported. Identical domains are deduplicated. The updater validates BM7 baseline counts, rule types, and non-empty supplement sources; failed validation prevents a commit.

## Usage

```ini
RULE-SET,https://raw.githubusercontent.com/Rongwuyou/Surge/main/Rules/Google.list,Google,extended-matching,no-resolve
```
