# Multi-source Surge Rules

These files are generated by `.github/scripts/update_rules.py` and synchronized daily by GitHub Actions at 00:00 Beijing time.

BM7 `blackmatrix7/ios_rule_script` is the baseline. Directly corresponding categories from v2fly, Rabbit-Spec, Loyalsoldier, and MetaCubeX are used as supplemental sources. BM7 rules are preserved, while supplemental `DOMAIN` and `DOMAIN-SUFFIX` semantics are retained and semantically deduplicated. Supplemental IP, ASN, keyword, and regex rules are not imported.

The updater checks BM7 baseline counts, supplemental source minimums, rule syntax, CIDR and ASN values, and unexpected output-size changes. Pull requests fail when committed rule files do not match the generated result.
